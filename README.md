# ManejoEventoJavaFX_3

Proyecto desarrollado en Java utilizando JavaFX y Maven para la práctica avanzada del manejo de eventos en interfaces gráficas de usuario.

## Descripción

Esta aplicación continúa con las prácticas de JavaFX enfocadas en el manejo de eventos, trabajando con diferentes componentes gráficos e interacciones dentro de la interfaz.

El proyecto permite reforzar cómo se gestionan las acciones del usuario en una aplicación de escritorio, utilizando eventos en JavaFX de forma progresiva.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven

## Requisitos

- JDK 17 o superior
- Maven instalado
- IDE compatible con JavaFX (IntelliJ IDEA, Eclipse o NetBeans)
